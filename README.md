# 🧪 Testes e Qualidade de Código

> **Repositório destinado aos estudos e exercícios desenvolvidos durante o módulo de Testes e Qualidade de Código da EBAC.**

Este repositório reúne os projetos e exercícios realizados durante o módulo, abordando ferramentas de análise estática, formatação de código e testes automatizados em aplicações React e Next.js.

O objetivo é documentar minha evolução no aprendizado, compreender a importância da qualidade de código e desenvolver habilidades para testar componentes, funções e integrações, contribuindo para aplicações mais confiáveis e fáceis de manter.

## 🚀 Tecnologias

- Next.js
- React
- TypeScript
- JavaScript (ES6+)
- Jest
- React Testing Library
- ESLint
- Prettier
- Axios
- API do TMDB

## 📚 Conteúdo estudado

- Linting e análise estática de código
- Configuração e utilização do ESLint
- Formatação automática com Prettier
- Integração entre ESLint e Prettier
- Fundamentos de testes de software
- Tipos de testes: unitários, integração e end-to-end
- Pirâmide de testes
- Configuração do Jest em projetos Next.js
- Testes de integração com React Testing Library
- Consumo e integração com APIs
- Padrão AAA (Arrange, Act, Assert)
- Execução automatizada de testes com Jest Watch

## 📂 Estrutura do repositório

> A organização das pastas acompanha a sequência dos módulos e exercícios desenvolvidos durante o curso.

O repositório contém exercícios e projetos utilizados para praticar os conceitos estudados, incluindo a aplicação **Cinelista**, desenvolvida com Next.js e integrada à API do TMDB.

## ⚙️ Como executar

Cada projeto possui sua própria estrutura e configuração.

Acesse a pasta do projeto desejado:

```bash
cd nome-do-projeto
```

Instale as dependências:

```bash
npm install
```

Para executar a aplicação, caso o projeto possua o script de desenvolvimento configurado:

```bash
npm run dev
```

Para executar os testes automatizados, consulte os scripts disponíveis no `package.json` de cada projeto.
